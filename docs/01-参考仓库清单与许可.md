# 01 · 第三方参考仓库清单（含许可与可用度评级）

> 本地路径 `third_party/`（**已被 `.gitignore` 排除，不会提交**），共 23 个浅克隆仓库、约 1.9 GB。
> 星级/更新时间为调研时（2026-10-15）从 GitHub 实查所得；标"未核实"处即未取到。
> 可用度评级：**A** = 可直接拿来用在平台上 ｜ **B** = 需改造但价值高 ｜ **C** = 只能当参考资料 ｜ **D** = 不要用

## 六、调研中被纠正的"看起来存在其实不存在"

| 说法 | 事实 |
|---|---|
| PyPI 有 `sports` 包 | **没有**。`roboflow/sports` README 明写从源码装：`pip install git+https://github.com/roboflow/sports.git` |
| `open-st/openst` 仓库 | **404，不存在** |
| `mm4spa/sportsfield_release` | **不存在**；MM4SPA 组织只有 `tvcalib`/`eigd`/`project`。真仓库是 `vcg-uvic/sportsfield_release` |
| Roboflow 的 `football-players-tracking` 等是 notebook | 它们是 **Universe 数据集名**；仓库内实际是 `examples/soccer/notebooks/train_{player_detector,pitch_keypoint_detector,ball_detector}.ipynb` |
| NBJW 和 PnLCalib 是两篇论文 | **同一个 arXiv 条目 2404.08401**：v1 = NBJW (CVPRW'24)，v5 = PnLCalib (CVIU 2026) |
| `MetricSports` 数据集 | 查无此数据集，疑为 **Metrica Sports** 之误 |
