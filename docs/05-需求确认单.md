# 附：为什么只问这 6 条（可跳过）

需求可以分成两类，它们的**获取方式完全不同**：

- **外部约束类**（Q1–Q6）：客户是谁、是否商业化、要多快、怎么拍、做多大范围、你能投入多少。这些**没法靠做原型发现** —— 你不可能通过跑一个检测器反推出自己的商业模式。所以必须**先定**。
- **内部期望类**（Q8/Q9 那类：精度够不够、哪些指标真有用）：这些**在没见过第一版输出之前，谁也答不准**。所以不在这里问死，而是留给「最小原型 → 看输出 → 再确认」这一步。这正是上一版我把 14 条技术选项一次摆给你、让你觉得别扭的原因。

至于**纯实现细节**（存 Parquet 还是 CSV、视频用 OpenCV 还是 PyAV、代码是包还是脚本）：这些完全可逆、换起来半天的事，我直接定就行，不该占用你的决策。
